## 什么是实时协作？

实时协作（Real-time Collaboration）是指多个用户 **同时** 编辑和操作同一份数据，并能 **即时** 看到彼此的变更。Google Docs、Figma、Notion 等产品的核心功能都依赖于此。

### 核心技术挑战

| 挑战 | 说明 |
|------|------|
| **通信** | 如何将用户操作实时传递给其他人 |
| **冲突解决** | 多人同时编辑同一位置怎么办 |
| **因果一致性** | 确保操作的先后顺序被正确保留 |
| **最终一致性** | 所有用户最终看到相同的结果 |

### 主流技术方案


## 🖥️ 方案 A：BroadcastChannel 多标签页同步

**零依赖、零后端**，利用浏览器原生 API 实现同一浏览器内多个标签页的数据同步。

### 使用方式

> 打开两个浏览器标签页，访问同一页面，在画布中移动鼠标、拖拽方块、或输入文字。

::CollabBroadcast
::

### 技术要点

```js
// 创建频道
const channel = new BroadcastChannel('my-collab')

// 发送消息
channel.postMessage({
  type: 'cursor',
  payload: { x: 100, y: 200 }
})

// 接收消息
channel.onmessage = (event) => {
  const { type, payload } = event.data
  // 处理消息...
}
```

### BroadcastChannel 特点

| 特点 | 说明 |
|------|------|
| ✅ 零依赖 | 浏览器原生 API，无需安装任何库 |
| ✅ 零后端 | 不需要任何服务器 |
| ✅ 同步快 | 同进程通信，延迟极低 |
| ⚠️ 同源限制 | 只能在同一浏览器的同源标签页之间通信 |
| ❌ 跨设备 | 无法实现不同设备之间的同步 |

## ✏️ 方案 B：CRDT 协同文本编辑

基于 **CRDT（Conflict-free Replicated Data Types）** 思想实现的协同文本编辑器，使用 **Lamport 逻辑时钟** 实现因果排序。

### 使用方式

> 打开两个标签页，在编辑器中同时输入文字，观察内容自动合并和操作历史记录。

::CollabCRDT
::

### CRDT vs OT

```
OT（操作转换）                 CRDT（无冲突复制数据类型）
├── 需要中心服务器                ├── 去中心化，可 P2P
├── 操作需要转换                  ├── 操作可直接合并
├── 实现复杂度高                  ├── 数据结构设计精巧
└── Google Docs 使用              └── Figma / Yjs 使用
```

### Lamport 逻辑时钟

```js
// 每次本地操作：时钟 + 1
function createOperation() {
  logicalClock++
  return { ..., clock: logicalClock }
}

// 接收远端操作：取最大值 + 1
function applyRemoteOp(op) {
  logicalClock = Math.max(logicalClock, op.clock) + 1
  // 应用操作...
}
```

时钟的作用是建立操作之间的 **偏序关系**（partial order），确保因果一致性：如果操作 A 发生在操作 B 之前，那么 A 的时钟值一定小于 B。

## 关键知识点

### 最终一致性（Eventual Consistency）

所有副本在 **接收到全部操作** 后，最终会 **收敛到相同的状态**，即使操作的到达顺序不同。

```
标签页 A：  输入 "Hello" ──────➡️ 收到 "World" ──➡️ "HelloWorld" ✅
标签页 B：  输入 "World" ──────➡️ 收到 "Hello" ──➡️ "HelloWorld" ✅
```

### 冲突解决策略

| 策略 | 原理 | 适用场景 |
|------|------|----------|
| LWW（Last Writer Wins） | 时间戳最大的写入胜出 | 状态同步、配置 |
| OT（操作转换） | 操作在应用前根据并发操作进行变换 | 文本编辑 |
| CRDT | 数据结构本身保证合并无冲突 | 文本、列表、计数器 |

### 工业级实现

如果需要生产环境的协同编辑，推荐使用成熟的 CRDT 库：

- **[Yjs](https://yjs.dev/)**：最流行的 CRDT 实现，支持 WebSocket / WebRTC
- **[Automerge](https://automerge.org/)**：JSON 兼容的 CRDT 库
- **[Liveblocks](https://liveblocks.io/)**：商业化的实时协作 SDK
